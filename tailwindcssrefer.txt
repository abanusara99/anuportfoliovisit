# 🔥 Tailwind CSS Classes Reference

## 🎨 Fire Theme Colors
| Class | Hex | Usage |
|-------|-----|-------|
| `border-orange-300` | `#fdba74` | Dull orange border for unselected contact icons |
| `border-orange-400` | `#fb923c` | Medium fire glow ring (hover/unselected state) |
| `border-orange-500` | `#f97316` | **Primary fire color** - selected contact icons |
| `border-orange-600` | `#ea580c` | Deep orange-red for intense glow effects |
| `text-orange-500` | `#f97316` | Hover text color for copy buttons |
| `hover:ring-orange-400` | `#fb923c` | Ring glow on contact detail boxes |

## ✨ Custom Glow Effects (Arbitrary Values)
| Class | Effect |
|-------|--------|
| `shadow-[0_0_15px_rgba(251,146,60,0.3)]` | Soft orange glow (unselected icons) |
| `shadow-[0_0_20px_rgba(249,115,22,0.5)]` | Enhanced fire glow on hover |
| `shadow-[0_0_25px_rgba(249,115,22,0.7)]` | **Intense fire pulse** (selected state) |

## 🔄 Custom Animations (globals.css)
| Class | Description |
|-------|-------------|
| `animate-pulse-fire` | Fire-themed pulsing glow animation (orange→red intensity shifts) |
| `animate-fade-in` | Smooth fade + slide-up animation for revealed content |
| `fire-glow` | Base class for fire shadow effects (defined in CSS) |

## 📱 Layout & Structure
| Class | Purpose |
|-------|---------|
| `flex flex-col md:flex-row` | Column on mobile → row on tablet/desktop |
| `items-center md:items-start` | Centered mobile → top-aligned desktop |
| `rounded-full overflow-hidden` | Creates perfect circular containers |
| `group relative` | Enables parent-hover effects on child elements |
| `absolute inset-0` | Full-container positioning for glow rings |
| `transition-all duration-500 ease-in-out` | Smooth 500ms fire glow transitions |

## 🌡️ Interactive States
| Class | Behavior |
|-------|----------|
| `group-hover:opacity-70` | Glow ring brightens on icon hover |
| `hover:scale-105` | Subtle icon growth on hover |
| `hover:ring-2 hover:ring-orange-400` | Contact boxes pulse with fire ring on hover |
| `hover:text-orange-500` | Copy buttons glow orange on hover |
| `activeContact === 'email' ? 'scale-110' : 'scale-100'` | Selected icon pops forward |

## 🖼️ Image Handling
| Class | Effect |
|-------|--------|
| `object-cover w-full h-full` | Maintains aspect ratio while filling container |
| `brightness-90 saturate-90` | Dulls unselected icons |
| `brightness-125 saturate-150` | **Enhances selected icons** with fire vibrancy |
| `rounded-full` | Circular clipping for profile/contact images |

## 📏 Spacing System
| Class | Value | Usage |
|-------|-------|-------|
| `p-3` | 12px | Icon container padding |
| `mt-6` | 24px | Space above revealed contact details |
| `gap-8` | 32px | Space between contact columns |
| `max-w-xs` | 320px | Contact detail box width |
| `space-y-3` | 12px | Vertical spacing between email entries |

## 🌐 Responsive Breakpoints
| Prefix | Min Width | Usage |
|--------|-----------|-------|
| `md:` | 768px | Tablet+ layout changes (columns, alignment) |
| `group-hover:` | N/A | Parent hover effects on child elements |
| `activeContact ===` | JS | Dynamic state-based styling |

## 💡 Pro Tips
1. **Fire Glow Formula**:  
   `shadow-[0_0_{size}px_rgba({R},{G},{B},{opacity})]`  
   → Orange: `249,115,22` | Red-Orange: `234,88,12`

2. **Animation Priority**:  
   Selected state > Hover state > Base state  
   (Ensures fire pulse dominates visual hierarchy)

3. **Border Strategy**:  
   - Outer border: `border-4` (main container)  
   - Glow ring: `border-2` (absolute positioned ring)  
   - Prevents visual thickness conflicts

4. **Performance Note**:  
   Use `transition-all` sparingly - we limit to critical interactive elements only

## 🚫 Deprecated Patterns
| Avoid | Use Instead | Why |
|-------|-------------|-----|
| `border-yellow-400` | `border-orange-500` | Yellow lacks fire intensity |
| `animate-pulse` (default) | `animate-pulse-fire` | Default pulse is too subtle for fire theme |
| `opacity-50` on icons | `brightness-90 saturate-90` | Preserves icon detail while dimming |

## 💡 Pro Tips

### 1. **Fire Glow Formula**
```
shadow-[0_0_{size}px_rgba({R},{G},{B},{opacity})]
→ Orange: 249,115,22 | Red-Orange: 234,88,12
```

### 2. **Animation Priority**
Selected state > Hover state > Base state  
(Ensures fire pulse dominates visual hierarchy)

### 3. **Border Strategy**
- Outer border: `border-4` (main container)
- Glow ring: `border-2` (absolute positioned ring)
- Prevents visual thickness conflicts

### 4. **Spacing Scale Reference**
```
0 = 0px
1 = 4px
2 = 8px
3 = 12px
4 = 16px
5 = 20px
6 = 24px
8 = 32px
10 = 40px
12 = 48px
16 = 64px
20 = 80px
24 = 96px
32 = 128px
40 = 160px
48 = 192px
56 = 224px
64 = 256px
```

### 5. **Responsive Strategy**
- Mobile first: Default styles for mobile
- `md:` for tablets (768px+)
- `lg:` for laptops (1024px+)
- Use `md:flex-row` to switch from column to row layout

### 6. **Performance Note**
Use `transition-all` sparingly - we limit to critical interactive elements only
